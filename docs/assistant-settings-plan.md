# 助手设置与基础档案使用

更新：2026-10-26。对应[主计划](development-plan.md)的 R1，尚未实现。助手的名称和表达风格与用户本人的 profile 是两个对象，分别管理。

## R1.1 助手设置

目标：助手身份与沟通风格属于 Namo，由执行器适配层传递；以后切换 Codex、Claude Code 等执行器时保留相同设置，不承诺不同模型输出完全一致。本项不改变现有服务、配置和数据，实施与上线分别验收。

- [ ] 在 `namo ui` 增加助手设置：名称、角色和性格描述，以及默认语言、回复长度、结论优先、技术细节程度和 emoji 使用偏好；首版采用有限结构化字段及有长度限制的描述，不建设通用提示词平台。
- [ ] `namo init` 提供可直接使用的默认风格和可跳过的简单选择；已有安装缺少新字段时保持现有行为，不要求重新配对或清空数据。
- [ ] 提供无需调用模型的示例预览、恢复默认、版本冲突校验及保存 / 生效状态说明；预览不冒充真实模型效果。设置由本机授权管理入口修改，聊天内容不能自动改写全局性格。
- [ ] 分离服务行为约束、助手性格与表达偏好、项目 `AGENTS.md` 和当前任务要求。性格、项目约定及用户偏好均不能扩大权限、替代审批或弱化隐私与结果真实性要求；强制执行边界继续由 R3 负责，提示词不视为安全隔离。
- [ ] 明确表达偏好的冲突规则：权限范围内当前任务的明确要求优先；项目输出约定适用于对应项目交付；用户偏好只在允许的接收场景覆盖助手默认值。项目 `AGENTS.md` 保留为开发约定，不自动继承宿主 Codex 对话或个人全局性格。
- [ ] 每次运行记录实际采用的设置版本，在途运行固定该版本，修改从后续运行生效；续接旧 session 时刷新设置并说明旧上下文残留的限制，必要时引导新建工作线。恢复默认只影响助手设置，不清空档案、会话或权限。
- [ ] 协调模型回复和 Namo 固定通知 / 卡片的表达：先统一默认文案与展示规则，再明确哪些设置适用于系统通知；状态、证据、错误和审批信息不因角色或精简风格而省略、扭曲。与 [飞书日常回复](chat-experience.md) 共用展示规则。

已有结构化档案的显式使用提前到 R1 的第二个交付项，规则见下节。自然对话提取、长期偏好与项目知识仍在 R6；首版助手设置不依赖自动学习、跨 session 记忆或后台自我改写。

验收标准：旧配置升级保持原行为；设置保存、重启、恢复默认与并发修改可验证；新运行采用新版本而在途任务不变；新建与续接 session 均验证设置应用；两用户、私聊 / 群聊及不同项目的偏好不串用；“直接推送”等性格描述不能获得操作授权；短回复仍保留必要失败、未验证及待确认信息。第二执行器接入时复用同一设置契约并验证能力差异。

## R1.2 使用已有结构化档案

这是本次重排提前的最小交付：让已经保存的称呼、语言和时区在明确范围内产生效果，不增加自动记忆能力。

- [ ] 本机管理入口明确说明并设置档案是否用于回答；旧安装默认沿用当前不注入的行为，不能因升级静默改变用途。
- [ ] 首批只在本人已验证的私聊中装配其已保存字段；群聊保持助手默认设置，不注入私人档案。身份继续使用渠道 / 应用 / 用户复合键，不能按正文姓名匹配。
- [ ] 当前任务的明确要求优先于个人默认值；时区只在日期时间相关任务中使用，不自动修改调度或页面全局设置。
- [ ] 运行保存采用的助手设置和档案版本；已开始的运行不随设置修改漂移，恢复新一轮时按规定刷新并记录。删除、停用和清空影响后续上下文，说明旧 session 残留并提供新建入口。
- [ ] 验证两用户、私聊 / 群聊、新旧 session、保存与重启后的读取，以及“这次用英文”不会改写长期默认值。

聊天中提取长期偏好、从迁移材料启用记忆以及项目知识检索，按[用户信息与长期记忆计划](user-memory-plan.md)的 R6 实施。
