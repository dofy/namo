# Namo 品牌与 Logo

**项目名：Namo**
**定位：本地优先的 AI 编程代理网关**
**描述：住在本地，帮你把事情做完的小狐狸。**

主标识为 [namo-logo.png](../assets/namo-logo.png)：朝右侧坐的橙色狐狸，使用大耳朵、闭眼笑意和环抱身体的尾巴表现机灵、放松与可靠。形象来自项目提供的两张狐狸参考图的构图及配色方向，生成时重新设计。

- 主色方向：暖橙 `#F58A24`。
- 辅色方向：奶油白 `#FFF2D8`。
- 轮廓方向：炭黑 `#22252A`。
- PNG 为 1254 × 1254，具有真实透明通道；保持比例和四周留白。
- README 使用 176 px 宽的主标识。需要极小尺寸图标时，应另做简化版，避免直接把毛发与表情细节压缩到 16 px。
