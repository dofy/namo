# M1 消息与任务模型验收

日期：2026-10-26。范围为本地源码、隔离数据库与子进程协议测试；未切换在线接收端，未推送或发布。

## 已验证

- `pnpm test`：62 项通过。原有队列、发送不确定性、初始化和权限测试继续通过。
- 新增结构化消息、话题 / 引用、异常富文本、材料等待 / 过期 / 归属、材料引用、输入上限和事务回滚验证。
- 新增排队修订、运行追加四类结果、领取到执行之间的补充竞争、重复事件、重启时提交结果不明不重送验证。
- 新增跨聊天同项目串行 / 跨项目并行、项目与权限快照、取消归属与先落库再中断验证。
- 新增话题与工作线 session 隔离、显式续接、旧项目选择与同用户旧 session 继承验证。
- 实际子进程模拟器验证 `turn/steer` 的目标 turn、回执、明确拒绝和完成竞争；本机 Codex 生成的协议 schema 确认必填字段为 `threadId / expectedTurnId / input`，响应含 `turnId`。
- `pnpm run smoke:codex` 通过初始化、官方登录和指定权限检查；该命令不运行真实推理。
- 旧结构 fixture 迁移与重复打开通过；拒绝未知未来 schema；真实数据库私有快照迁移后，原始 `inbox / outbox / sessions / settings` 所有历史字段及记录保持一致，SQLite integrity_check 为 ok，外键检查无错误。
- 最终检查确认在线配置与 Codex 登录文件未变，在线四表保持原样、schema 仍为 0；原服务保持同一 PID，连接为 connected、ready 为 true。

## 已实现但待在线验收

维护窗口中使用新版完成真实飞书的材料 → 指令 → 执行、运行追加、工作线续接和任务取消验证。不能把模拟协议通过当成模型已理解修订，也不能把平台创建消息回执当成用户已读。

## 明确限制

- 附件 / 合并转发只保存资源描述，未下载解析；逐条转发若表现为普通文字，需用 `/material` 显式提交。
- 引用只关联本机已知的本人任务或同话题待处理材料；未知引用要求粘贴内容，不自动抓取历史。
- 运行中补充仅通过明确 `/amend` 或任务引用关联；不自动判断任意自然语言插话属于哪个任务。
- 不提供跨聊天 session 共享、长期记忆、独立后台 runner、可视化配置或卡片按钮；这些保留在后续阶段。
- 结果未知不自动重试；暂无自动核对 / 重发界面。升级后的库不能直接交回旧版消费，参见 [运维与回退](operations.md)。
