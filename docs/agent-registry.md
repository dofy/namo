# 旧 Codex 配置与任务兼容

当前只运行官方 Codex，管理页及配置 API 不再提供 Agent 注册表。命令发现、登录状态、环境和协议检查统一放在工作台的**连接设置**中。

为了避免改变已创建任务的执行身份，内部保留以下兼容行为：

- 旧配置中的 Codex profile 仍使用原有默认选择、独立登录目录、模型和超时设置。`namo login --profile ID` 仅兼容这些已有 Codex 配置；工作台诊断使用当前默认配置。
- 任务和工作线的 profile 快照、配置修订、策略哈希及原生 session 映射保持原算法；未配置注册表的实例继续使用 `codex` 和原有 `codex.home`。
- 旧 Claude / Cursor 预登记项不进入运行时；将其设为默认或请求使用时明确失败，不回退到其他账号或执行器。
- 普通设置保存不删除或改写磁盘上的旧注册表，不清理既有认证文件或数据。
- 后台记忆固定使用内置 Codex。

未来插件扩展见[接口预留](agent-adapters-plan.md)。这里的兼容代码不提供插件注册或加载功能。
