# 助手设置与基础档案使用

更新：2026-10-26。对应[主计划](development-plan.md)的 R1。schema 8 实现已把设置核心、显式档案装配、静态预览、管理 API、双语 UI、初始化可跳过选择和 `buildTaskRunPrompt` 接入主 Engine；新 run 固定采用版本，恢复已有 runner job 时复用其持久化 prompt。历史发布和真实 Codex 记录见[交付台账](archive/roadmap-delivery.md)，真实飞书验收缺口见[后续计划](development-plan.md)。助手的名称和表达风格与用户本人的 profile 是两个对象，分别管理。

## 助手设置

目标：助手身份与沟通风格属于 Namo，由执行器适配层传递；以后切换 Codex、Claude Code 等执行器时保留相同设置，不承诺不同模型输出完全一致。本项不改变现有服务、配置和数据，实施与上线分别验收。

- [x] 在 `namo ui` 增加助手设置：名称、角色和性格描述，以及默认语言、回复长度、结论优先、技术细节程度和 emoji 使用偏好；采用有限结构化字段及有长度限制的描述，不建设通用提示词平台。
- [x] `namo init` 提供可跳过的设置步骤；已有安装缺少设置键时保持未启用，不要求重新配对或清空数据。
- [x] 提供无需调用模型的示例预览、恢复默认、版本冲突校验及保存 / 生效状态说明；预览不冒充真实模型效果。设置由本机授权管理入口修改，聊天内容不能自动改写全局性格。
- [x] 分离服务行为约束、助手性格与表达偏好、项目 `AGENTS.md` 和当前任务要求。性格、项目约定及用户偏好均不能扩大权限、替代审批或弱化隐私与结果真实性要求；R3 本身也只提供有限保护，提示词不视为安全隔离。
- [x] 明确表达偏好的冲突规则：权限范围内当前任务的明确要求优先；项目输出约定适用于对应项目交付；用户偏好只在允许的接收场景覆盖助手默认值。
- [x] 每次新运行记录实际采用的设置版本，在途运行固定该版本，修改从后续运行生效；恢复已有 runner job 时不重建 prompt。恢复默认只影响助手设置，不清空档案、会话或权限。
- [x] 固定通知、状态、证据、错误和审批文案不采用助手性格字段，避免精简风格省略或扭曲事实。与[飞书日常回复](chat-experience.md)共用展示规则。

已有结构化档案的显式使用提前到 R1 的第二个交付项，规则见下节。自然对话提取、长期偏好与项目知识仍在 R6；首版助手设置不依赖自动学习、跨 session 记忆或后台自我改写。

验收标准：旧配置升级保持原行为；设置保存、重启、恢复默认与并发修改可验证；新运行采用新版本而在途任务不变；新建与续接 session 均验证设置应用；两用户、私聊 / 群聊及不同项目的偏好不串用；“直接推送”等性格描述不能获得操作授权；短回复仍保留必要失败、未验证及待确认信息。第二执行器接入时复用同一设置契约并验证能力差异。

## 使用已有结构化档案

这是本次重排提前的最小交付：让已经保存的称呼、语言和时区在明确范围内产生效果，不增加自动记忆能力。

- [x] 本机管理入口明确说明并设置档案是否用于回答；旧安装默认不注入，不能因升级静默改变用途。
- [x] 只在本人已验证的私聊中装配其已保存字段；群聊保持助手默认设置，不注入私人档案。身份使用渠道 / 应用 / 用户复合键，不能按正文姓名匹配。
- [x] 当前任务的明确要求优先于个人默认值；时区只在日期时间相关任务中使用，不自动修改调度或页面全局设置。
- [x] 运行保存采用的助手设置和档案版本；已开始的运行不随设置修改漂移。删除、停用和清空影响后续运行；旧 session 可能残留并提供新建入口。
- [ ] 验证两用户、私聊 / 群聊、新旧 session、保存与重启后的读取，以及“这次用英文”不会改写长期默认值。

显式长期记忆与迁移候选启用见[记忆契约](memory.md)；普通聊天不会自动提取并保存偏好。

## 已实现的独立契约

`src/assistant.ts` 提供以下不依赖管理界面和执行器实现的契约：

- `AssistantSettings.read / save / reset / preview`：设置采用严格、完整字段校验；未知字段、控制字符、超长内容和非法枚举均拒绝。`save / reset` 必须携带当前版本和由本机管理边界派生的 `OwnerEditContext`，事务内再次比较版本。调用方不得从请求 JSON 直接构造“已认证”状态。
- 旧安装没有 `assistant:settings:v1` 时返回 `version = 0, active = false`，组合提示词保持逐字不变，不因升级启用默认性格或档案。首次保存或恢复默认产生版本 1 并从后续运行生效。
- `AssistantSettings.adopt(runId, context)`：在一个事务中读取助手设置、符合条件时读取档案，并把采用的设置版本、档案版本和时间写入 `settings` 表的 `assistant:run:<runId>`。该记录不复制称呼、语言或时区；同一 runId 不允许二次采用，避免在途运行漂移。返回值及嵌套值被冻结，供调用方一次性生成运行 prompt。
- 档案只有同时满足所有条件才装配：助手设置已显式启用 `useProfile`；调用方按当前配置确认 `channel + appId + userId` 是已配对本人；持久库 `account` 与 appId 相同；入站消息的系统 sender 与 userId 相同；消息 key 属于该 app；系统元数据明确为 `p2p` 的文字指令。正文姓名、引用作者和聊天内容均不参与身份判断。群聊、身份不明、其他应用和其他用户一律不装配。
- 称呼和语言可进入符合条件的运行快照；时区还要求调用方把本次任务标为日期时间相关。即使档案已清空，符合条件的运行仍记录其版本 tombstone，但不恢复或复制旧字段。
- `composeAssistantPrompt` 明确顺序为：服务行为与授权边界 > 当前任务明确要求 > 对应项目输出约定 > 合格的用户档案偏好 > 助手默认值。精简风格不能省略状态、证据、错误、未验证项、隐私限制或审批要求；设置不能授予权限。续接 session 会加入旧上下文可能残留的说明，但不自动清空或重放 session。
- `ui/pages/AssistantPage.tsx` 是独立、双语的 Radix 页面，通过 props 接收状态和 `save / reset / preview / refresh` 动作，不引用 Node、SQLite 或配置实现。它展示旧行为 / 已启用状态、版本、冲突、后续运行生效说明、档案使用边界和非模型预览声明。

默认结构化值可直接使用，但只在明确保存后启用：Namo、Local AI work companion、清晰务实且重视权限 / 隐私 / 证据的性格，跟随当前任务语言，平衡长度，结论优先，平衡技术细节，少量 emoji，档案使用关闭。恢复默认只写助手设置的新版本，不删除其他 `settings`、档案、会话、任务或权限。
