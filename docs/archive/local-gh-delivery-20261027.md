## 实现

- 中英文 UI / CLI 提供本机 gh 登录、独立令牌及仅公开仓库三种选择。本机登录绑定一个配对用户的本人私聊，无需另建令牌或仓库白名单。
- 保存 gh 路径、配置目录与账号身份。凭据只在服务内存中使用，不保存到 Namo 配置或模型输入；不继承环境令牌、调试或代理配置。
- GitHub 读取仍使用固定域名、固定 GET 接口、响应大小与期限限制，禁止重定向。先核对凭据所属账号，再读取固定 PR HEAD 和精确检查项。
- 恢复前重新读取实际权限及检查结果，并再次核对当前配置、任务归属与等待状态；退出登录、权限撤销、检查变化、取消和超时不会错误恢复任务。
