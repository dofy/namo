# M1 异常核对与 M2 第一批验收

日期：2026-10-26。范围为异常核对、本地管理界面、配置保存 / 应用和基础任务卡片。代码与隔离验证完成，在线服务未切换；未推送、未发布。

## 实现范围

- `namo ui`：项目 / 权限配置、任务 / 工作线、运行与投递详情、异常处理、连接诊断，以及官方登录和飞书配对的 CLI 引导。
- 配置共用校验，保存前备份并检测冲突；保存与应用分开，报告当前配置是否生效。应用需明确确认、兼容后台服务及空闲队列；不会启动第二接收端。
- `/issues /issue /resolve` 及同名 CLI：人工确认收到、指定结果分段重发、放弃发送、标记执行已核对；快照条件和唯一请求保护，审计事务持久化，不重跑模型。
- 可选固定接收 / 结果卡片，按钮查看状态或请求停止。校验用户、聊天、平台消息、有效期与重复请求；停止额外核对当前任务版本和状态。默认 `cards=false` 保持已有文字配置。
- schema 2 增加两张表和一个出站 payload 字段；管理界面读取旧 schema 不迁移，旧库写操作拒绝。
